# Kanban — доска задач

Простая доска задач с колонками и карточками. Все данные хранятся в `localStorage`
браузера — без бэкенда, без внешних API, без сторонних сервисов.

## Возможности

- Колонки и карточки: добавление, переименование (двойной клик), удаление
- Перетаскивание карточек между колонками и внутри колонки (на нативном
  HTML5 Drag and Drop, без сторонних библиотек)
- Автосохранение в `localStorage` — данные остаются после перезагрузки страницы
- Светлая/тёмная тема с переключателем (использует те же цвета и шрифты,
  что и основной сайт-портфолио)

## Стек

React 19 + Vite. Из зависимостей — только `react`/`react-dom` в проде;
`gh-pages` нужен только для деплоя.

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой на GitHub Pages

1. В `vite.config.js` в поле `base` укажи имя своего репозитория, например
   `/kanban-board/` (если сайт будет на корне — `username.github.io` — поставь `/`).
2. Запусти:

   ```bash
   npm run deploy
   ```

   Скрипт соберёт проект и запушит папку `dist` в ветку `gh-pages` репозитория.
3. В настройках репозитория на GitHub: Settings → Pages → Source →
   Deploy from a branch → ветка `gh-pages`, папка `/ (root)`.
4. Через минуту-две сайт будет доступен по адресу
   `https://username.github.io/kanban-board/`.
